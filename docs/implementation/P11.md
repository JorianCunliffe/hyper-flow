# Phase 11 — API parity and tenant operations

Status: first account/API release live; Phase 11 remains in progress and is not accepted. Phase 10's internal workflow release is recorded separately; selected publishing providers remain unresolved.

## Implemented for the first release

- HyperFlow-owned API credentials use salted scrypt hashes, explicit endpoint read/write scopes, expiry, human administrator creation/rotation/revocation, current creator membership and a transactional daily API-client request budget. Credentials cannot create further credentials or change the budget. No plaintext secret is stored or returned. Clients supply their own high-entropy URL-safe secret; the API returns its credential prefix. A read response omits hash fields. UTC usage retains 90 days; the current bounded control record retains 1,000 administration events and at most 100 client identities. These are API-client request counts, not provider charges or all browser traffic.
- Express and Vercel expose /api/tenant. Request scope resolution accounts for rewritten business endpoints, so a Communications read scope cannot authorize a rewritten operational or integration endpoint. Unknown machine endpoints fail closed; Firebase human sessions remain supported.
- /api/workspace GET/PUT exposes the existing project/settings/scratch/activity snapshot with tenant dataRevision and per-project revision checks. It retains the existing browser save semantics. Operational commitments, flows, artifact files, calendar/publishing records and credentials remain separate stores. The existing browser still uses Firebase saves; it has not yet been migrated by this work. The REST write is capped at 3.8 MB and 500 projects.
- Account operations UI exposes scopes, one-time credential display, recoverable creation/rotation, revocation, budgets and audit. Lost-response retries preserve the original secret and request identity. Machine credentials cannot mutate these controls.
- Flow and artifact lists provide bounded summary pages and explicit continuation cursors. Selecting a flow fetches its full record. Project-filtered artifact pages retain continuation even when a page contains no visible records.
- Organization changes, logout and subscription permission loss clear the current cloud view and its safety backup. Revocation displays an access-unavailable screen. Local-only workspace storage is not deleted.
- The standalone TypeScript client pins its origin, keeps its credential private, accepts request cancellation and never automatically retries uncertain writes. `contracts/phase11.openapi.json` is an addition-specific supplement, not the complete product inventory.
- Final local verification: 552 tests passed, TypeScript passed, production build passed and production dependency audit found zero vulnerabilities. Real Firebase integration and controlled browser fixtures cover concurrent workspace updates, tenant/scope boundaries, forbidden browser credential access, revocation, cursor pages and lost-response credential recovery. Evidence is retained alongside this record; release and production verification are still pending.
