Status: internal draft, approval, adapter contract and visible-flow implementation validated locally; release verification in progress. Selected-provider implementation and live publication acceptance remain pending the user's social account/page, CMS/site and permitted reversible test change. No public change has been made.

HyperFlow owns content, source notes, versions, grants, Asks, dispatch claims and observations. Communications is unchanged. No memory extraction or new memory application.

Publishing saves social or website text with internal source notes. Editing archives the old version and invalidates approval. A configured target preview pins the provider revision and grant. A designated administrator separately approves the exact public content. Publishing claims once and verifies by read-back; uncertain results remain held. The empty production adapter registry permits drafting and blocks publication.

A saved version can create an unapproved visible review flow. The flow waits for separate publication and fresh reconciliation. Edits invalidate its pinned content. A flow approval does not substitute for public-use approval. Publication never automatically fulfills a promise.
